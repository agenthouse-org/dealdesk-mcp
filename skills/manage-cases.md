# Create and update DealDesk cases

Tools: `dealdesk.list_cases`, `dealdesk.get_case`, `dealdesk.create_case`, `dealdesk.patch_case`

List, get, create, and patch local DealDesk cases. This is not Salesforce Opportunity search.

Allowed tools: dealdesk.list_cases, dealdesk.get_case, dealdesk.create_case, dealdesk.patch_case

Never call DELETE tools.
