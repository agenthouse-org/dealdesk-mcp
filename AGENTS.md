# Contributing

Thank you for your interest in the DealDesk plugin.

This repository is the customer-facing plugin for DealDesk on agenthouse (skills + local MCP bridge). Please keep documentation and package metadata professional and suitable for end users: clear install steps, no internal implementation paths, and no references to private issue trackers.

The tool runtime lives on agenthouse at `POST /mcp/dealdesk`. Keep shipped skills aligned with that catalog.

Report bugs and feature requests via [GitHub Issues](https://github.com/agenthouse-org/dealdesk-plugin/issues).

For product questions, contact your agenthouse representative or visit [agenthouse.org](https://agenthouse.org).
